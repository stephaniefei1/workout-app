# Lift Log - Fat Loss Guide

A private, phone-friendly PWA built from the resistance workouts, warm-up routine, schedule, daily step targets, and embedded demo URLs in `Fat Loss Guide.pdf`.

## Use it on a phone

The app needs to be served from a website address (not opened as a local file) for offline mode and installation to work.

1. Publish this `fat-loss-tracker` folder to any static host, such as GitHub Pages, Netlify, or Cloudflare Pages.
2. Open the resulting `https://` address on the phone.
3. On iPhone, tap **Share → Add to Home Screen**. On Android, use the browser's **Install app** prompt.

All logs are stored only in the browser on that device. Use **Settings → Export backup** periodically; importing that file restores a backup on the same or a different device.

## Included source guide content

- Every day in the six-week schedule, including daily step goals and cardio duration
- The shared dynamic warm-up routine
- Four resistance workouts for weeks 1-3 and four progressive workouts for weeks 4-6
- Original YouTube demonstration links embedded in the guide

The guide's exercise names and prescriptions are reproduced as practical tracking data. This app is not medical advice; follow the guide's form cues and consult an appropriate professional for individual training questions.
